# Sound assets

Presentation sound cues load from this folder at runtime. Each cue maps to a filename:

| File          | Cue            | Beat                |
|---------------|----------------|---------------------|
| `dice.wav`    | dice clatter   | `DiceRolledBeat`    |
| `save.wav`    | deflection ping| `SaveBeat`          |
| `wound.wav`   | hurt grunt/thud| `ModelWoundedBeat`  |
| `death.wav`   | death thud     | `ModelDiedBeat`     |
| `banner.wav`  | stage sting    | `BannerBeat`        |
| `move.wav`    | footsteps      | `UnitMovedBeat`     |

## Attack sounds (#239 — per weapon effect set)

Attacks are voiced per **weapon effect set** (the `effectSet` keys in army/book data). Each ranged
set has a firing cue and an impact cue; each melee set a swing cue and a connect cue. Filenames are
`<kind>-<set-key>.wav`:

| Pattern              | Fires when                                    |
|----------------------|-----------------------------------------------|
| `fire-<set>.wav`     | a ranged volley leaves the barrel             |
| `impact-<set>.wav`   | a ranged volley that HIT lands on the target  |
| `melee-<set>.wav`    | a melee swing starts                          |
| `meleehit-<set>.wav` | a melee swing that HIT connects               |

Ranged set keys: `plasma-bolt`, `fusion-melta`, `flame-jet`, `gravity-pulse`, `gauss-particle`,
`laser-beam`, `missile-rocket`, `mortar-artillery`, `bio-organic`, `storm-tracer`,
`ballistic-slug` (global default), `arcane-psychic`, `shard-crystal`.

Melee set keys: `energy-blade`, `titan-impact`, `shock-melee`, `chain-blade`, `toxic-melee`,
`daemon-arcane-melee`, `spear-pierce`, `claw-rend`, `crude-melee`, `blade-standard` (global default).

Example: `fire-plasma-bolt.wav` + `impact-plasma-bolt.wav` voice every plasma weapon in every army.
Whiffed volleys never play an impact/connect cue — only shots that actually hit do.

Any file that's missing falls back to a **distinct synthesized placeholder per cue**, so every beat
and every effect set sounds different before real assets exist. The tones are generated by
`ToneSynth`; the per-cue recipes live in `PresentationSoundCues.PlaceholderSamples`. Drop a `.wav`
here with the matching name and it takes over automatically — no code change. The beat->cue mapping
lives in `PresentationSoundCues` (`CueFor` / `VolleyCue` / `ImpactCue`); the set keys come from
`WeaponEffectCatalog` (visual styles) and `WeaponEffectAssigner.Sets` (the key vocabulary).

`.wav` is safest with Raylib; `.ogg`/`.mp3` also load but the cue keys assume `.wav` filenames
(adjust `PresentationSoundCues.LoadInto` if you use another extension).
